# SocketLens 0.1.0

The first portfolio release of SocketLens.

## Included

- private/loopback TCP target inspection
- bounded concurrent scanning
- port/service table
- persistent SQLite snapshots
- change detection
- recent scan history
- JSON export
- embedded single-binary dashboard
- automated verification and CI

## Scope

This release intentionally does not scan public Internet targets or implement intrusive security testing.
